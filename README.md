# Ecombio Storefront (Hydrogen)

Shopify Hydrogen storefront for Ecombio, with Algolia AI Search & Discovery
being integrated on top of the default Shopify search experience.

> For a running log of decisions, dates, and open questions, see
> [`PROGRESS.md`](./PROGRESS.md). This README documents current, stable
> state — update it when setup steps or architecture change, not for
> day-to-day progress notes.

---

## Stack

| Layer | Choice |
|---|---|
| Framework | [Hydrogen](https://shopify.dev/docs/storefronts/headless/hydrogen) (React Router, SSR) |
| Language | TypeScript |
| Styling | Tailwind v4 |
| Commerce backend | Shopify Storefront API (`ecombio.myshopify.com`) |
| Markets | Subfolders (`/fr-ca/...`, etc.) |
| Search | [Algolia](https://algolia.com) — `react-instantsearch` v7 (hooks API) |
| Hosting target | Shopify Oxygen |

## Branch strategy

This repo (`ecombio/storefronts`) hosts multiple, largely unrelated
codebases across branches — **check you're on the right one** before
touching anything.

| Branch | Contents |
|---|---|
| **`hydrogen`** | ← **this branch.** The Hydrogen/React Router storefront. |
| `liquid` | The legacy Shopify Liquid theme. |
| `main` | *(confirm current purpose before assuming — historically used for scaffold work; do not treat as authoritative without checking)* |
| `agentic`, `pilot`, `shipit`, `site` | Other experiments — not part of this build. |
| `shopify-setup-oxygen-workflow-*` | Auto-generated by Shopify's GitHub integration when connecting a storefront to Oxygen for CI/CD. Safe to ignore/delete once merged or superseded. |

**Do not merge `hydrogen` into `main` or vice versa** without an explicit
decision — these branches currently contain different, non-interchangeable
projects (Hydrogen app vs. Liquid theme), not divergent versions of the
same one.

## Getting started

```powershell
git clone https://github.com/ecombio/storefronts.git
cd storefronts
git checkout hydrogen
npm install
npm run dev
```

Open `http://localhost:3000`.

### Environment variables

Copy `.env.example` → `.env` and fill in:

```
PUBLIC_STORE_DOMAIN=ecombio.myshopify.com
# Shopify Storefront API tokens — pulled automatically if linked via `npx shopify hydrogen link`

PUBLIC_ALGOLIA_APP_ID=
PUBLIC_ALGOLIA_SEARCH_KEY=   # search-only key — never the admin key
```

Never commit `.env`. Use the **search-only** Algolia API key for anything
client-side; the admin key must never ship to the browser.

## Search: Algolia integration

- **Search library:** `react-instantsearch` **v7** (hooks-based). Do **not**
  install or reference `react-instantsearch-dom` — that's the deprecated v6
  API and is incompatible with this codebase's patterns.
- **Reference-only repo:** [`algolia/pwa-ecom-ui-template`](https://github.com/algolia/pwa-ecom-ui-template)
  is used for UX/component *patterns* only. It's a Next.js app on the
  deprecated v6 API — nothing from it is copy-pasted directly; patterns are
  translated into v7 hooks and Hydrogen/React Router conventions. Clone it
  as a sibling folder if you need to reference it locally, never as a
  submodule or merge target:
  ```powershell
  git clone --depth 1 https://github.com/algolia/pwa-ecom-ui-template.git ../algolia-reference
  ```
- **Docs:** Algolia's current documentation index is at
  [`algolia.com/doc/llms.txt`](https://algolia.com/doc/llms.txt) — use it to
  find the exact `.md` reference page for a given widget
  (`.../widgets/<name>/react.md`) before implementing or changing one.

## Notes / known gaps

- No `CurrentRefinements` / `ClearRefinements` UI yet — active filters
  aren't visible or removable as a group.
- No empty-state (`NoResultsHandler`-equivalent) handling on `/search`.
- Oxygen CI/CD GitHub Actions workflow was removed during a branch
  history reset and needs to be reconnected via the Shopify Hydrogen
  admin channel (Storefront settings → reconnect repo) before
  push-to-deploy will work again.

See `PROGRESS.md` for full history and reasoning behind these gaps.
