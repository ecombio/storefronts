# E-Bike Laws: Overview and Laws-Hub Plan

Working reference for the Ecombio laws content. Compiled 2026-10-01 from a single round of web search. Most sources are manufacturer or retailer blogs, so treat this as orientation only. **Verify every item against the state statute or DMV page before publishing, and date the page.** This is a general overview, not legal advice.

## 1. The layers of e-bike law

E-bike rules come from several bodies, and each answers a different question.

| Layer                        | Who sets it                               | What it decides                                                                                                                                                       |
| ---------------------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Federal product definition   | Consumer Product Safety Commission (CPSC) | What counts as an e-bike as a consumer product (commonly summarized as a 750W motor limit)                                                                            |
| Federal land access          | Land agencies (national parks, forests)   | Which trails allow e-bikes; a 2019 policy opened many non-motorized trails on federal land to Class 1 and 2, but individual parks and forests can set their own rules |
| State vehicle classification | State legislature                         | Whether an e-bike is a bicycle, and which class it falls in                                                                                                           |
| State rider rules            | State legislature                         | Helmets, minimum age, licence, registration, insurance, impaired riding                                                                                               |
| Local access rules           | Cities, counties, park agencies           | Bike lanes, paths, sidewalks, trails                                                                                                                                  |
| Product and battery rules    | Federal, state, local                     | Labeling, battery labeling and safety, certification standards                                                                                                        |

### Key facts

- The Class 1/2/3 system is **not** federal law. The CPSC chair said in 2023 that it "is not part of CPSC's statutes." It began as an industry model bill that states adopted.
- In states that use the three classes, an e-bike is generally exempt from vehicle registration, licensing and insurance, because it is not classed as a motor vehicle.
- In three-class states, manufacturers must label the bike with its class, top speed and motor wattage.

## 2. The three classes (general outline)

| Class   | Assist                                        | Typical top assisted speed |
| ------- | --------------------------------------------- | -------------------------- |
| Class 1 | Pedal-assist only                             | 20 mph                     |
| Class 2 | Throttle (may also pedal-assist)              | 20 mph                     |
| Class 3 | Pedal-assist only, usually with a speedometer | 28 mph                     |

Some states define the classes slightly differently. Check the exact wording of each state's statute.

## 3. Rider rules that vary by state

| Topic           | Typical pattern                              | Notes                                                                                                                                        |
| --------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Helmets         | Most inconsistent rule; tends to track speed | California requires a helmet on Class 3 for all riders and passengers (CVC §21213). Connecticut requires one for every rider, class and age. |
| Minimum age     | Usually attached to Class 3                  | Several states set a minimum age for Class 3, typically 16.                                                                                  |
| Licence         | Rarely required for classed e-bikes          | Mopeds and motorized bicycles are treated differently.                                                                                       |
| Registration    | Rare among states                            | The great majority of states do not require it.                                                                                              |
| Insurance       | Rare for classed e-bikes                     | Reported for reclassified bikes in New Jersey (verify).                                                                                      |
| Impaired riding | DUI laws apply in many states                | Check each state.                                                                                                                            |
| Where to ride   | Varies by class and by local rule            | Class 3 can face extra limits on shared-use paths.                                                                                           |

## 4. 2026 changes (verify each against the statute)

| State          | Change                                                                                                                                                                         | Date                                            | Confidence                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- | ------------------------------------------------------------------------ |
| New Jersey     | S4834 (signed January) largely abandons the three-class system. One source says all e-bikes become motorized bicycles with licensing, registration and insurance requirements. | 2026                                            | Reported by several sources; read the statute for the exact requirements |
| Washington     | SB 6110 keeps the three classes but narrows what qualifies as an e-bike                                                                                                        | June 11, 2026                                   | Single source                                                            |
| Hawaii         | Creates a three-class system; raises the youth helmet age; bans high-speed "e-Moto" devices from public roads                                                                  | Signed July 15, 2026                            | Single source                                                            |
| North Carolina | Adopts the three-class system                                                                                                                                                  | Signed July 7, 2026; effective December 1, 2026 | Single source                                                            |
| California     | Changes effective January 1, 2026                                                                                                                                              | 2026                                            | Details not found                                                        |
| Tennessee      | Changes effective July 1, 2026                                                                                                                                                 | 2026                                            | Details not found                                                        |

Other notes:

- Sources disagree on how many states use the three classes (figures of 36 states plus DC and 41 states both appeared). Do not print a number without checking.
- Nearly 700 bike-related bills were reportedly introduced nationwide in 2026, covering definitions, registration, battery labeling and trail access. Laws are changing quickly.
- The three-class framework was built for pedal bicycles, and other personal electric vehicles are outside it.

## 6. Laws-hub plan for Ecombio

Aventon's own crawl shows its laws and classes posts are the most heavily linked pages on its blog, so this topic earns its weight. It is also where an out-of-date sentence does the most harm.

### Structure

1. **Pillar:** federal definition, the three classes, and how to read your state's rules
2. **State pages:** one per state Ecombio ships into, each covering class definition, helmet, age, licence and registration, where to ride, and the 2026 changes
3. **Cluster posts:** Class 3 explained, helmets by state, e-bike laws for kids, riding on sidewalks and trails, travelling with an e-bike across states

### Page standard

- Cite the statute or the official DMV page for every rule
- Show a "Last verified" date and a review schedule (quarterly at minimum)
- Link to the relevant collection (for example Class 3 bikes) and to the pre-purchase guide
- Do not call any product "legal" without stating the state and class
- Add a short disclaimer that this is general information

### Before writing

- [ ] List the states Ecombio ships into, in order of sales
- [ ] Pull each state's statute text and DMV page
- [ ] Settle New Jersey with the statute before writing anything on it
- [ ] Confirm what the California and Tennessee 2026 changes are
